# Hangman-Game-Python
An interactive Hangman word guessing game built using Python and Tkinter.

About the Project

This project is an interactive Hangman word guessing game developed using Python and Tkinter.

Features

- Graphical user interface
- Multiple word categories
- Random word selection
- Difficulty levels
- Feedback for correct and incorrect guesses

Technologies Used

- Python
- Tkinter

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the main Python file:

python main.py

Learning Outcomes

This project helped me practise Python programming, conditional statements, functions, and GUI development.
